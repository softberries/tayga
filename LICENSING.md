## What the AGPL means for you

You can use, modify and run Tayga freely, including in production. If you modify Tayga and let other people interact with that modified version over a network (for example as a hosted service), the AGPL requires you to offer those users the complete source code of your modified version under the same license.

## Commercial license

A commercial license removes the AGPL obligations, including the source-offering requirement for modified versions run as a network service. It is also the way to get the enterprise edition.
