## The open-source core

The AGPLv3 lets you use, study, modify and share Tayga, including commercially. Its main conditions, in short:

- **Share alike.** If you distribute Tayga or a modified version, you do so under the AGPLv3 and make the corresponding source code available.
- **Network use counts.** If you modify Tayga and let users interact with it over a network, you must offer those users the source code of your modified version. Running an unmodified Tayga does not trigger this clause.
- **No warranty.** Tayga is provided as is.

The full text is in the [`LICENSE`](https://github.com/softberries/tayga/blob/master/LICENSE) file, and [`LICENSING.md`](https://github.com/softberries/tayga/blob/master/LICENSING.md) summarises how the two licenses relate.
