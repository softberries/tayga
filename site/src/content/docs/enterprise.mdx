## What it includes

<CardGrid>
	<Card title="Identity and access" icon="padlock">
		Single sign-on with **SSO / SAML**, user provisioning with **SCIM**, **fine-grained RBAC**, and **audit logs** of who did what.
	</Card>
	<Card title="Multi-tenancy and federation" icon="random">
		**Multi-tenancy** to keep teams and customers apart, and **multi-cluster federation** to see several clusters from one place.
	</Card>
	<Card title="High availability and scale" icon="rocket">
		**High-availability** and **scale-out deployment**, with **upgrade tooling** for moving between versions safely.
	</Card>
	<Card title="Privacy and compliance" icon="approve-check-circle">
		**PII redaction policies** applied to telemetry, and **data-residency controls** for where data is stored.
	</Card>
	<Card title="Long-term baselines" icon="analytics">
		Compare a release with **previous deploys**, not only with the last hour, to see whether a change made things worse.
	</Card>
	<Card title="Enterprise integrations" icon="puzzle">
		**ServiceNow**, **Jira** and **PagerDuty** integrations, so stories and alerts reach the systems your teams already work in.
	</Card>
	<Card title="LLM incident summaries" icon="comment-alt">
		Incident summaries written by a large language model, with **bring-your-own model**, so your telemetry goes only to the model you choose.
	</Card>
	<Card title="Support" icon="heart">
		**Support with an SLA**, **onboarding** and **training** for your teams.
	</Card>
</CardGrid>

## Open source and Enterprise

| Capability | Open source (AGPLv3) | Enterprise |
|---|---|---|
| Error and slow stories, story groups, root cause, critical path, baseline diff | Yes | Yes |
| Log templates and new / spike / silence alerts | Yes | Yes |
| Service map, trace explorer, pipeline health | Yes | Yes |
| Webhook and Slack alert delivery | Yes | Yes |
| Authentication | One account, no roles | SSO / SAML, SCIM, fine-grained RBAC, audit logs |
| Tenancy | Single tenant | Multi-tenancy, multi-cluster federation |
| Deployment | Docker Compose, Helm, from source | High availability, scale-out, upgrade tooling |
| Baselines | The last 60 minutes per endpoint | Long-term: compare a release with previous deploys |
| Privacy controls | Not included | PII redaction policies, data-residency controls |
| Integrations | Webhook, Slack | ServiceNow, Jira, PagerDuty |
| Incident summaries | Not included | LLM summaries with your own model |
| Support | Community, through GitHub | SLA, onboarding, training |
| License | AGPLv3 | Commercial |
