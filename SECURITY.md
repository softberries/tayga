# Security policy

## Reporting a vulnerability

Please do not report security issues in public issues, pull requests or discussions.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/softberries/tayga/security/advisories/new), or by email to [hello@softberries.dev](mailto:hello@softberries.dev). Include the Tayga version, how it is deployed (Docker Compose, Helm or from source), and the steps to reproduce the issue.

You will get a reply acknowledging the report. Once the issue is confirmed, a fix is prepared in a private advisory and released, and the advisory is published with credit to you unless you ask otherwise.

## Supported versions

Security fixes go into the latest release. Upgrade to it to get them; see [Upgrading](https://softberries.github.io/tayga/install/upgrading/).
